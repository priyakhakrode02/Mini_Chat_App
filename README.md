# Mini Chat App

A simple chat application built using JavaScript, HTML, CSS, and MongoDB. It allows users to create, view, edit, and delete chat messages.

## Features
- Create new messages.
- View chat messages.
- Edit existing messages.
- Delete messages.
- Store chat messages in MongoDB.
- Perform CRUD operations.

## Tech Stack
- *Frontend:* HTML, CSS
- *Backend:* JavaScript
- *Database:* MongoDB
